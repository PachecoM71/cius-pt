# CIUS-PT 2.1.1 Schematron

Published by eSPap (Entidade de Serviços Partilhados da Administração Pública) as `urn_feap.gov.pt_cius-pt_schematron.zip` (Documento.ashx?id=267) with the CIUS-PT 2.1.1 specification of 26 February 2021. Reproduced unchanged. The package compiles these files into `src/rules/cius-pt-2.1.1.ts` with `npm run compile-rules`; the rule ids and messages in validation output are eSPap's.

Files: the root `urn_feap.gov.pt_CIUS-PT_2.1.1.sch` declares four phases; `all_phase` activates the UBL-syntax, UBL-model, UBL-datatype and UBL-condition patterns, which is what this package runs.
